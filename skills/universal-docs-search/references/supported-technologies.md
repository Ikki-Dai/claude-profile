## 搜索技巧

### 基础搜索
- 使用技术名称: `react hooks`, `go generics`, `rust async`, `python asyncio`
- 添加特定功能: `authentication`, `configuration`, `deployment`, `optimization`
- 包含版本号: `node.js 18`, `python 3.10`, `java 17`, `go 1.20`

### 高级搜索
- 组合关键词: `kubernetes docker networking`, `react performance optimization`
- 问题导向: `how to implement oauth2 in node.js`, `rust memory management explained`
- 错误排查: `python import error`, `javascript async await`, `docker permission denied`

### 跨语言搜索模式
- **概念搜索**: `generics programming`, `async patterns`, `dependency injection`
- **架构模式**: `microservices architecture`, `event driven design`, `clean architecture`
- **性能优化**: `database indexing`, `caching strategies`, `load balancing`

### 搜索优化
- 使用英文关键词获得更多结果
- 包含官方术语和概念名称
- 指定具体的方法名或类名
- 结合错误消息进行搜索
- 使用技术关键词 + 实际场景
